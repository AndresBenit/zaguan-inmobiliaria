# Zaguán Propiedad Raíz · proyecto concepto

Inmobiliaria ficticia de venta y arriendo en Bogotá, diseñada y construida por [Andrés Benítez](https://www.andresbenitez.lat) como demo de portafolio. Página privada: no se indexa.

- Portada con inmuebles destacados que rotan a pantalla completa
- Buscador que filtra por operación, zona, presupuesto y habitaciones
- 18 inmuebles de ejemplo con ficha, galería y agendador de visitas por WhatsApp
- Mapa real de Bogotá (OpenStreetMap) con el precio de cada inmueble
- Proceso de acompañamiento para comprar y para arrendar
- Sección para propietarios con solicitud de avalúo
- Calculadora de crédito hipotecario

Inmuebles, precios, personas y dirección son de ejemplo. Los inmuebles se editan en `app/_components/data.ts`. Fotos de Unsplash (ver `public/img/CREDITOS.txt`).

```bash
npm install
npm run dev
```
